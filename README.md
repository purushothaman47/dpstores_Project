Description

  This is a Spring Boot application for managing products in a store.
  It provides basic operations like creating and viewing product data using REST APIs.

Project Structure
    DpStoreApplication.java – Main Spring Boot application
    Product.java – Product model/entity
    ProductController.java – REST API controller
    ProductService.java – Business logic
    ProductRepository.java – Database operations
    DataCreater.java – Sample data creation

Technologies Used
    Java
    Spring Boot
    Spring Data JPA
    REST API

How to Run
  Open the project in IntelliJ / Eclipse
  Make sure Java and Maven are installed
  Run DpStoreApplication.java
  Application will start on the default Spring Boot port

Features
    Add product details
    Fetch product details
    Layered architecture (Controller, Service, Repository)
